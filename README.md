# 經典地產棋 ClassicEstate

使用 **Swift 與 SwiftUI** 製作的地產棋小遊戲，支援 2–4 位玩家共用一台裝置輪流遊玩。透過擲骰、購買土地、收取租金及升級土地，體驗資產競賽，也練習以 `if-else` 實作遊戲規則。

## 開發環境

- 開發工具：Xcode
- 程式語言：Swift 5.0
- 介面框架：SwiftUI
- 最低系統需求：iOS 17.0
- 支援裝置：iPhone、iPad

## 執行方式

1. 下載完整專案，保留以下資料夾結構。
2. 使用 Xcode 開啟 `ClassicEstate.xcodeproj`。
3. 選擇搭載 iOS 17.0 或以上版本的模擬器。
4. 按下 Run 執行；若使用實體裝置，需先設定簽署團隊。

```text
ClassicEstate/
├── ClassicEstate.xcodeproj/
├── ClassicEstate/
│   ├── ClassicEstateApp.swift
│   ├── GameModel.swift
│   └── ContentView.swift
└── Tests/
    └── GameModelSmoke.swift
```

> 分享專案時，請同時包含 `.xcodeproj` 與存放 Swift 原始碼的 `ClassicEstate` 資料夾。

## 主要功能

- 設定 2–4 位玩家與玩家姓名。
- 24 格環狀棋盤與雙骰移動。
- 土地購買、收租及升級。
- 隨機機會事件、稅金與監獄。
- 玩家現金、總資產及遊戲紀錄顯示。
- 首位玩家破產或指定輪數兩種結束模式。
- 結算排名與同資產並列名次。
- 遊戲規則說明與重新設定功能。

## 遊戲玩法

### 開始遊戲

選擇玩家人數、輸入姓名並設定結束條件，再按下「開始遊戲」。每位玩家起始現金為 **$1,500**，從起點出發。

每回合按下「擲兩顆骰子」，依點數總和前進。處理落點事件及購買、升級操作後，按下「結束回合」換下一位玩家。擲出相同點數不會增加額外回合。

### 棋盤規則

| 格子 | 效果 |
|---|---|
| 起點 | 經過或抵達時領取 $200 |
| 無主土地 | 現金足夠時可購買，也可略過 |
| 他人土地 | 自動支付租金給地主 |
| 自有土地 | 再次停留時可升級一次，需有足夠現金 |
| 機會 | 隨機觸發獎金、費用、移動、入獄或玩家間付款 |
| 稅金 | 支付 $120 |
| 監獄／探訪 | 正常抵達只算探訪，不必停留 |
| 前往監獄 | 移到監獄並進入服刑狀態 |
| 免費停車 | 不產生額外效果 |

### 土地升級

- 購買當次不能升級。
- 再次停在自有土地時，可升級該土地一次。
- 每次升級費用等於土地原價。
- 土地等級沒有設定上限。

```text
基本租金 = 土地原價 × 40%
實際租金 = 基本租金 ×（土地等級 + 1）
```

### 監獄

入獄後，下次擲骰若兩顆點數相同，可立即出獄並前進；否則停留該回合，下回合恢復自由。被送進監獄不會獲得起點獎金。

### 破產與結算

現金不足以付清費用時，玩家支付剩餘現金後破產，土地收歸銀行並清除升級等級。現金剛好足夠付款時，即使付完剩下 $0，也不會立即破產。

遊戲提供兩種結束模式：

- **首位玩家破產：**有人破產時立即結束。
- **指定完整輪數：**可選擇 1–50 輪，預設 10 輪；若只剩一位未破產玩家，則提前結束。

每位仍在場的玩家依序完成一次回合算一輪，監獄停留也計入。指定輪數模式的最後一回合仍可購買或依規則升級，按下「結束回合」後才結算。

排名先比較是否破產，再比較總資產；破產狀態與總資產相同者並列。

```text
總資產 = 現金 + 土地原價總和 + 已投入的升級費用
```

## 程式架構

| 檔案／型別 | 職責 |
|---|---|
| `ClassicEstateApp.swift` | App 進入點，顯示主畫面 |
| `GameModel.swift` | 遊戲資料、規則、回合及排名計算 |
| `ContentView.swift` | 設定、遊戲、規則及結果介面 |
| `Player` | 玩家現金、位置、監獄與破產狀態 |
| `BoardCell` | 格子種類、價格、地主與升級等級 |
| `SetupState` | 玩家人數、姓名與結束條件等設定 |
| `EstateBoardView` | 棋盤排列與玩家位置呈現 |
| `EstateCellView` | 單一格子的資訊與外觀 |

遊戲狀態由 `ObservableObject` 與 `@Published` 管理，畫面透過 `@StateObject` 保存物件，隨資料變更更新顯示內容。

## if-else 應用重點

- `canBuy`：檢查遊戲狀態、土地所有權與現金是否足夠。
- `canUpgrade(_:)`：確認地主、升級機會及升級費用。
- `roll()`：判斷能否擲骰，以及監獄中的玩家能否移動。
- `resolveLanding()`：依格子種類及地主身分處理事件。
- `chance()`：依隨機結果執行七種機會事件。
- `pay(...)`：判斷正常付款或進入破產流程。
- `endTurn()`：切換玩家、跳過破產者並檢查輪數。
- `ContentView`：依遊戲狀態切換設定、遊戲及結算畫面。

## 目前範圍與未來改進

目前為共用裝置的真人輪流遊玩版本，採現金不足即破產的簡化規則，尚未提供電腦玩家、網路連線、存檔、抵押、出售、交易或拍賣功能。

未來可加入棋子移動動畫、音效、存檔與電腦對手，並擴充更多土地經營策略。
